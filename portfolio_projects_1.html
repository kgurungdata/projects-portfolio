Excel · Reusable Tool

Attendance Tracker — Reusable Template

A general-purpose attendance-tracking workbook, built so it can be reused for any event without rebuilding the formulas from scratch. Includes a numbered "how to reuse this" guide directly in the workbook.

  • Live formulas throughout — no hardcoded results (INDEX/MATCH, COUNTIFS, AVERAGEIFS)
  • Conditional formatting: color-scaled attendance rates, data bars, group color-coding
  • Built-in instructions for updating contact lists, groups, and attendance records for a new event
Skills: Excel formulas, template design for reusability, conditional formatting, documentation

Excel · Issue Resolution

Helpdesk Escalation Ticket Analysis

An analysis of a simulated 30-ticket helpdesk queue, focused on identifying which problem categories escalate most often and why — comparing resolution time for escalated vs. first-line-resolved tickets and breaking down escalation reasons.

  • Escalation rate by category with a color-scaled summary table and bar chart
  • Pie chart of escalation reasons (admin access needed, hardware replacement, vendor involvement, repeat/root-cause issues)
  • Written read-out of what the data shows and why certain categories escalate more
Skills: Issue categorization, root-cause thinking, Excel formulas and charting, written data interpretation
